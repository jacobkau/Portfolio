# Jacob Mwambwa Kau - Developer Portfolio

A modern, responsive, and interactive personal portfolio website showcasing my work as a Full Stack Developer and UI/UX Designer. Built with a "Neo-Brutalist" design aesthetic, featuring a developer-focused typography (Fira Code), smooth Framer Motion animations, and a fully tabbed interface.

## Live Demo
[Click me to view the portfolio](https://jacob-mwambwa-portfolio.vercel.app/)

## Features

*   **Interactive Hero Section:** Features a custom orbiting animation around the profile picture using Framer Motion.
*   **Tabbed Navigation:** A seamless, single-page application feel where users can switch between sections without full page reloads.
*   **Neo-Brutalist UI:** Custom heavy borders, hard drop shadows, and high-contrast color palettes.
*   **Developer Typography:** Utilizes Google's `Fira Code` monospace font for a terminal/code-editor aesthetic.
*   **Dynamic Projects Showcase:** Displays full-stack projects with direct links to live demos and GitHub repositories.
*   **Blogs & Testimonials:** Interactive modal system to read full articles, and WhatsApp-style chat bubbles for client testimonials.
*   **Working Contact Form:** Integrated with Formspree for seamless, serverless email delivery.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.

## Tech Stack

**Frontend:**

## Running Locally

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jacobkau/portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:5173` (or the port specified in your terminal).
